## 契约（机器可读）

上文每条 `[闸门]` 在这里必须有一个谓词。`internal/pipeline` 拿这份契约当流水线定义，
所以**没有契约块的阶段文件视为未落地**（`Load` 直接报错）。

可用判定：`present` / `nonempty` / `empty` / `is_true` / `equals` / `one_of` / `min_items`。
`when` 是前置：前置不成立则本条不适用；**前置字段缺失按不通过处理**（不接受说不清的前置）。
入口条件来自不同上游、打回的地方不一样时，用 `reject_upstream` 按交付物名覆盖 `reject_to`。

```json
{
  "id": "NN",
  "name": "<名字>",
  "produces": "<交付物名字>",
  "entry": [
    { "from": "<上游交付物>", "field": "<字段>", "check": "<判定>", "value": "<可选>" }
  ],
  "exit": [
    { "field": "<字段>", "check": "<判定>" }
  ],
  "publish": "前台事实",
  "reject_to": "<上游阶段编号>",
  "reject_upstream": { "<某上游交付物>": "<该打回的阶段编号>" }
}
```
